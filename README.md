## 优惠码失效的常见原因

### 优惠码已经过期

搬瓦工促销码往往不是长期开放。大促期间出现的优惠码，可能只在活动窗口内有效。活动结束后，旧文章通常不会自动消失，于是搜索结果里会同时出现有效信息和过期信息。

这也是为什么“某个网站写着可用”不等于你现在一定能用。

### 输入时带入了空格

从网页或聊天窗口复制优惠码时，前后可能带有空格、换行或不可见字符。可以手动重新输入一次，或者粘贴后检查首尾是否有多余字符。

### 套餐不符合优惠条件

有些折扣只适用于普通 VPS，或者只适用于特定地区、特定付款周期。搬瓦工当前购物车同时展示普通 KVM、CN2 GIA、E-commerce SLA 和 Dubai 等多类方案，价格和优惠适用范围可能不同。

### 优惠码不能叠加

多数结账系统一次订单只接受一个促销码。连续输入多个代码，不会把折扣简单相加，后输入的代码还可能覆盖前一个代码。

如果第一个码已经成功降低价格，通常没有必要继续测试其他码。

### 套餐已经下架或售罄

优惠码即使仍然有效，也不代表已经售罄的套餐可以购买。搬瓦工官网会动态展示当前可下单的方案，某些限量版产品可能会消失、补货或更换名称。

## 循环优惠是什么意思

搬瓦工优惠码页面中经常会出现循环折扣，也就是 `Recurring Discount`。它和一次性优惠的区别在于：

- 一次性折扣只影响第一次付款；
- 循环折扣可能继续作用于后续续费；
- 最终是否延续，以订单页面和账单页面实际显示为准。

不要仅凭优惠码名称判断它是不是循环优惠。付款前查看订单摘要、账单周期和续费金额。如果页面没有清楚显示，建议保留订单截图或账单记录。

对于年付 VPS，循环折扣的价值通常高于只减免首次订单的小额优惠。但如果优惠码只能用于首购，后续续费恢复原价，那么实际节省金额就要按完整使用周期重新计算。
